READY TO USE

需要的工具，已经在这里。

从游戏客户端到安装与更新，功能都有对应的验证记录。选择属于自己的配置。

01 / GAMING

游戏工具齐备

预装 Steam、Lutris、MangoHud、GameMode 与 Gamescope。Proton 和游戏内容联网后按需下载。

02 / FIREWALL

默认拒绝新入站

nftables 入站默认 drop，允许必要回包、ICMP 和 DHCP。正常出站保持开放。

03 / DESKTOP

Arch 与原生 KDE

官方 Arch 软件仓库、KDE Plasma 桌面和中文拼音。保留熟悉的终端与文件管理工具。

04 / INSTALL

图形安装与 LUKS2

Calamares 支持创建普通用户，安装时可选加密。ESP 与独立 /boot 保留明文。

05 / SNAPSHOTS

btrfs 与更新前快照

root、home 独立子卷与 Snapper 配置。更新工具先做快照和 boot 备份，恢复步骤有据可查。

06 / VERIFY

可核验的发布附件

提供 SHA-256、签名校验清单和公钥。自建仓库默认关闭，启用后要求包与数据库签名。

01下载、核验与重组

下载三个分片、校验清单和公钥，验证签名及散列，重组为完整 ISO。

02写入安装 U 盘

确认 ISO 散列后，用镜像写盘工具写入空 U 盘。写盘前核对目标盘符与容量。

03体验，然后安装

启动 Live 桌面，双击“安装 BasaltOS”。选择目标磁盘、加密选项并创建自己的账号。
